# Smriti: things to do

Running list. Items get built together in one update when you say go.

## 1. Progress tracker: how much you read each day
Show progress over time as **amounts per day** ("+5 pages today, +10 tomorrow"), not just where you're up to.

What's already there: every log entry is stored with its date, so this works for everything you've logged so far.
The tracker works out each day's amount from the difference between positions (p. 60 → p. 70 = +10 pages).

Plan:
- **On each book (per read)**: a "Progress" section with
  - a small bar chart, one bar per day from start to now (days with no reading show as gaps);
  - a day-by-day list: "4 Nov · +10 pages (p. 60 → 70)", newest first;
  - pace: days read, average per reading day ("~14 pages a day").
- **Overall (Stats)**: a daily chart for the last 30 days, all books combined, plus days read this year
  and average per reading day. Tap a bar to see that day's total and which books it came from.
- **Units**: pages for print and ebook (ebook % converted when the page count is known), **%** for an ebook with
  no page count, **minutes** for audiobooks. Pages and minutes are always kept apart, never added together.
- Several logs on the same day add up to one day's total.
- If you skip logging for a few days, the whole jump lands on the day you log it.

1. Do you also want to enter **"how much I read today"** (e.g. "+12 pages") in Log progress, as well as
   "the page I'm on"? (The +10 / +25 quick buttons already work this way.)
2. **Streaks** ("read 6 days in a row")? Could feel like a goal, which you said you don't want.
3. **Finish estimate** on the book ("at this pace, done around 20 Nov")? Same question.
